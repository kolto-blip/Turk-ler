
Түркілер

Кімдер?

Біздің тікелей ата-бабаларымыз. "Түрік" деген аты алғаш осы кезде пайда болды. Біз — түркілерміз!

Қашан өмір сүрді?

1500 жыл бұрын. 552 - 756 жылдары.

Қайда тұрды?

Алтайдан бастап, бүкіл Қазақстан, Орта Азия. Үлкен Түрік қағанаты құрды.

Не істеді?	
- Көк Түрік қағанатын құрды — үлкен мемлекет
- Мал бақты, темірден қару-жарақ жасады — ұсталар болды
- Жазу ойлап тапты: Орхон-Енисей жазуы — тасқа қашап жазды
- Ұлы Жібек жолымен сауда жасады
Қызықты дерек:
- Бумын қаған — Түрік қағанатының негізін қалаушы.
- Күлтегін, Тоныкөк — батырлары. Олардың тасқа жазған ескерткіштері әлі бар!
Есте сақта: Түркілер — темір балқытқан ұста, жазуы бар, бізге "қазақ" деген жолды ашқан бабалар!
